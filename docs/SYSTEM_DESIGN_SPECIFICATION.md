## 一、产品定位与系统全局愿景

### 1.1 产品愿景
千极AI旨在构建中国领先的、高度垂直于新一代 AI 开发者与算法工程师的高吞吐全周期生态系统。打通从**数据准备 (Dataset) → 算子与技能开发 (Skill) → 自主智能体工程化 (Agent) → 弹性硬件支撑 (GPU Compute) → 真实商业需求变现 (Tasks Bounty) → 算法技术对抗 (Competitions)** 的端到端闭环。

### 1.2 目标用户画像
1. **AI 架构师与大模型工程师**：寻找前沿开源框架实践、高吞吐算力容器与专用清洗语料；
2. **Agent 开发者与创作者**：发布并销售实用场景智能体（85% 高分成比例）、沉淀工具链 Skill；
3. **企业与悬赏任务发布方**：发布高难度 AI 算法研发与数据标注任务，依托平台资金/积分托管保障交付质量；
4. **技术极客与算法参赛者**：在竞技与悬赏中获取丰厚现金与积分回报，积累开发者信誉勋章。

## 二、全局设计规范与底层核心纪律

为保证千极AI系统的专业性、纯粹性与商业可信度，系统确立以下不可逾越的底层交互纪律：

### 2.1 评论区纯文本严控纪律（Text-Only Comment Rule）
* **核心规则**：全站所有业务模块（包括但不限于：极客社区帖子、Agent 智能体评论、Skill 技能评论、Dataset 数据集评论）的评论发布与二级回复，**仅支持纯文字输入**。
* **技术与界面约束**：
  * 彻底移除所有 Emoji 选择器、图片上传控件、贴图功能；
  * 前端与状态管理全局接入文字合规校验，对包含表情符号、图片标签或非文本格式内容进行实时拦截提示：“根据平台规范，评论内容仅支持纯文本，暂不支持表情符号或图片”。

### 2.2 发布任务“资金+积分”双重托管冻结纪律（Dual Escrow Principle）
* **核心规则**：发布悬赏任务属于高额履约行为。发布人提交任务时，所设置的全部现金赏金预算与激励积分，将在提交瞬间从用户可用账户扣除，并全额划入平台托管池（表现为【冻结资金】与【冻结积分】）。
* **生命周期流转规范**：
  1. **发布即冻结**：任务处于【审核中】或【进行中】期间，托管资金与积分被严格锁定，不可挪用、提现或抵扣消费；
  2. **验收即清算**：发布者确认某位接单者的交付成果并通过验收后，冻结的现金与积分自动划转给接单开发者；
  3. **驳回/取消即原路解冻退还**：若任务审核被驳回，或因特殊原因取消，平台立即全额解冻并原路返还至发布者的可用余额与可用积分账户；
  4. **超时退款保障**：任务截止期到达后，若出现“无人接单”、“接单人超时未提交”或“交付成果全部合规驳回”，系统自动触发全额原路退款结算机制。

### 2.3 积分经济学与价值锚定（Points Economics）
* **价值基准**：**1 积分 ≡ ¥0.01 元人民币**，价值恒定，可用于全站消费抵扣与算力租赁；
* **获取机制**：
  * 每日连续签到（基础 +5 分，连续 7 天额外 +20 分）；
  * 上传优质数据集并通过审核（+50 积分/个）；
  * 上传可复用 Skill 并通过审核（+50 积分/个）；
  * 社区发表高价值技术帖（+5 积分/次）；
  * 接单并成功通过任务验收（单次可获对应任务的丰厚配套积分悬赏，额外系统 +30 积分）；
* **有效期**：平台积分长期有效，不设衰减与到期淘汰机制。

### 2.4 纯净消息通知体系（Distraction-Free Notifications）
* **分类标准**：通知中心仅保留三类一级视图：
  1. **全部消息**：按时间倒序聚合；
  2. **业务通知**：AI 集市变动、任务接单/提交/验收/打款进展、算力实例启停与欠费、赛事评测结果、账户充值与扣费；
  3. **社区互动**：聚焦真实有效的内容互动（点赞、文本评论、二级回复、收藏、精华置顶）；
* **减噪规约**：彻底剔除社交噪点干扰，**不设立、不推送“您有新的关注者”与“有人在帖子中@了您”两类冗余通知**。

## 三、系统整体信息架构与用户角色体系

### 3.1 核心导航与功能模块映射
| 一级导航栏 | 对应核心视图 | 业务主旨 |
| :--- | :--- | :--- |
| **首页** | HomeView | 平台大盘概览、精选轮播、全生态高热资产流转、极客榜单与活动直通车 |
| **AI 集市** | MarketplaceView | Agent / Skill / Dataset 资产交易与分发，在线试用与 85% 开发者分成 |
| **任务大厅** | TasksView | 悬赏众包任务看板、需求发布、抢单承接、交付物流转与多阶段验收 |
| **算力工坊** | ComputeView | 云端 GPU 算力集群（A100/H800/4090）、JupyterLab 在线环境与按量计费 |
| **赛事中心** | CompetitionsView | 算法竞赛对抗、测试集评测、自动化沙盒打分、奖金池争夺与极客声誉排名 |
| **极客社区** | CommunityView | 技术沉淀、踩坑记录、纯文本互动讨论、模型训练与推理经验共享 |
| **个人工作台** | WorkspaceView | 资产管理、我的任务、算力实例监控、我的账户（含资金/积分冻结）、通知中心 |

### 3.2 用户角色与权限体系
1. **游客 / 未登录用户**：支持浏览集市、查看社区公开讨论帖、查看赛事公共榜单，执行试用、发布、接单、租算力时引导登录；
2. **认证极客（开发者）**：拥有完整的发布帖子、参与评论、接单承接任务、租用算力、兑换商城商品、发布资产权限；
3. **任务发布者（需实名认证）**：可发起大额悬赏任务，拥有预付款划扣托管、成果评审、分阶段验收权限；
4. **平台运营管理员（Admin）**：对发布任务合规性审查、AI 资产准入审核、争议申诉处理。

## 四、核心业务模块功能与交互设计规范

### 4.1 AI 运营中心（首页 Overview）
* **视觉与层级**：高质感深色/深蓝极客微质感风格，顶部主推荐 Banner 支持动态轮播，配高亮行动按钮直达当前重点活动；
* **核心看板矩阵**：
  * 平台生态统计：已上线 Agent 数、算力在线 GPU 核心数、悬赏任务总奖金池、活跃极客开发者规模；
  * 热门推荐聚合瀑布流：热度最高的 Agent、最新开源数据集、最新高额悬赏任务快速卡片；
  * 极客光荣榜：展示赛事排名前列与接单解决疑难算法的 Top 开发者。

### 4.2 AI 集市（Marketplace）
* **三大子品类**：
  1. **Agent 智能体**：面向业务场景的自主代理（如企业研报分析师、金融合规审查 Agent、代码重构助手），支持在线免配置体验与月卡/按次订阅；
  2. **Skill 工具集**：标准化插件与函数协议（如 WebGPU 渲染器、eBPF 监控组件、SIMD 加速算子），提供代码集成包与一键调用示例；
  3. **Dataset 数据集**：垂直领域语料（如医疗多轮对话、多语种语音音频、多模态图文对），配详尽样本结构与质检报告；
* **交互与规范**：
  * 多维分类检索、搜索建议与热度排序；
  * 详情页包含：简介、技术栈标签、API 调用方式、价格标准、开发者分润比例（固定 85% 打款至开发者账户）；
  * **评论互动区**：严格执行纯文本评论规则，杜绝灌水表情与图片。

### 4.3 任务大厅（Tasks Bounty Hall）
* **发布任务流程**：
  1. 发布者填写：任务标题、难度评级（初级/中级/困难）、所属技术领域、交付周期截止日；
  2. 奖励设定：设定单份/总额现金赏金（元）与激励积分（个）；
  3. 需求说明与验收标准：清晰明确的交付成果规范及自动化测试要求；
  4. 预付款校验：计算全额所需资金与积分，账户余额不足时弹出快捷充值引导；
  5. 托管划扣：确认发布后，现金转入【冻结资金】，积分转入【冻结积分】，任务进入【审核中】。
* **承接与交付流程**：
  1. 开发者申请接单并进入【进行中】；
  2. 开发者在截止时间前提交交付物（Git 仓库、代码压缩包、文档说明）；
  3. 发布人发起成果验收，支持多维度评测、代码审查；
  4. 验收合格则点击通过，系统自动划转资金与积分完成结算；若不符合标准则附驳回原因，触发退回修改或全额原路解冻退款。

### 4.4 算力工坊（Compute Lab）
* **算力资源池**：
  * 支持多种主流 GPU 实例规格（NVIDIA RTX 4090 24G、A100 80G SXM4、H800 80G、H100 NVLink、华为升腾 Ascend 910B 等）；
  * 计费模式：支持精确到分钟的按量计费（¥/小时）与高性价比包月长租；
* **实例生命周期交互**：
  * 一键启动实例、停止、重启、释放；
  * 内置集成 WebShell 终端、JupyterLab 远程工作区直达、SSH 密钥免密登录指令一键复制；
  * 账户余额与积分联合抵扣机制，低余额智能短信/邮件欠费预警，避免计算任务非预期中断。

### 4.5 赛事中心（Competitions）
* **竞赛体系**：大模型微调大赛、行业落地 Agent 创新黑客松、高并发推理优化对抗赛；
* **赛事生命周期**：报名筹备期 → 正式提交期 → 自动化沙盒打分 → 专家复核评选 → 颁奖发放现金与积分奖励；
* **评测机制**：支持标准化测试集评测、排行榜（Leaderboard）实时分数刷新、提交版本历史回溯。

### 4.6 极客社区（Geek Community）
* **核心内容流**：技术前沿、踩坑经验、论文复现、开源项目发布；
* **发帖规范**：支持 Markdown 渲染、代码高亮、多标签归类；
* **互动设计**：
  * 支持点赞、收藏、分享与优质帖子加精；
  * 评论区及楼中楼二级回复：**严格仅支持文字，禁止表情符号与图片**；
  * 净化通知：评论收到互动时仅推送真实讨论内容，不发送社交关注噪点。

### 4.7 个人工作台与账户体系（Workspace & My Account）
* **资产卡核心设计（WorkspacePoints.tsx）**：
  * **可用余额区**：直观展示人民币可用余额，配充值弹窗（支持微信、支付宝），底栏展示：`冻结资金：¥{frozenBalance} · 发布任务托管`；
  * **我的积分区**：展示积分余额及折算人民币价值（1积分=¥0.01），底栏展示：`冻结积分：{frozenPoints} 积分 (=¥{折合金额}) · 发布任务托管`；
  * **发布任务托管冻结概览看板**：独立展示被冻结的资金与积分总览，说明资金与积分双重托管保护机制，并配一键直达发布任务快捷按钮；
  * **5Tab 流水明细**：全部记录、充值流水、消费扣费、积分获取、积分消耗，支持关键字筛选与多维度检索；
* **通知中心（WorkspaceNotifications.tsx）**：
  * 保留三级 Tab（全部消息、业务通知、社区互动）；
  * 彻底剔除关注者与@提醒，专注核心业务履约与实质性技术讨论。

### 4.8 管理控制台（Admin Console）
* **审核流**：
  * 任务发布合规性初审与复审；
  * 数据集质量与合规检查；
  * Skill 代码包安全扫描与沙盒测试；
* **风控与争议仲裁**：接单人与发布人交付产生分歧时的平台仲裁通道。

## 五、文字设计优先（Text-First）协作与迭代流程指南

为了确保产品功能调整的严谨性、各端一致性与业务逻辑闭环，千极AI团队约定以下协作协议：

### 5.1 铁律流程
\`\`\`
[业务需求提出] 
       ↓
[第 1 步：修订 Google Drive 设计文档中的文字与规则描述]
       ↓
[第 2 步：审阅并确认文字规范（包含字段、状态流转、交互边界提示、文案）]
       ↓
[第 3 步：确认无歧义后，启动代码修改与前端/后端实现]
       ↓
[第 4 步：编译与自动化构建验证，验收并同步归档最新版本设计]
\`\`\`

### 5.2 文字设计审阅清单（Checklist）
在修改任何代码前，请检查文字设计是否明确了以下 6 点：
1. **触发时机**：该动作在什么场景、哪个按钮或哪个状态下被触发？
2. **前后状态流转**：涉及资金、积分、任务状态时，变化前和变化后的具体数字与枚举值是什么？
3. **异常与边界文案**：当余额不足、权限不够、非法输入（如非纯文本表情）时的确切提示语是什么？
4. **受影响模块**：除当前页面外，工作台资产卡、通知中心、交易流水等关联板块是否需要同步反映？
5. **用户知情权**：涉及资金冻结、扣费或数据删除的操作，是否有清晰的确认弹窗（Confirmation Dialog）？
6. **文字准确性**：文案是否符合开发者社区专业语境，避免口语化或含混表述。
